موقع بوابة الآليات المتحدة المحدودة (MGU) — الكود المصدري الكامل
================================================================

المحتويات:
1) مجلد website/
   الموقع الكامل (HTML / CSS / JS / PWA / الصور / الخطوط / البروفايل PDF / ملفات SEO).
   جاهز للرفع المباشر على أي استضافة ثابتة بدون أي تبعيات خارجية.

2) مجلد admin-panel/
   لوحة التحكم والإحصائيات وطلبات عروض الأسعار (Cloudflare Worker + KV + D1 + R2).
   - index.html: واجهة لوحة التحكم.
   - _worker.js: كود الـ API والإحصائيات وإدارة المحتوى.

أفضل طرق الاستضافة المجانية بملكية كاملة لك:
----------------------------------------------
1) Cloudflare Pages (موصى به — مجاني ويدعم الموقع + لوحة التحكم):
   - أنشئ حساباً مجانياً على dash.cloudflare.com
   - من Workers & Pages > Create > Pages > Upload assets
   - ارفع مجلد website/ وسينشر الموقع فوراً بملكية كاملة، ويمكنك ربط دومين خاص بك لاحقاً مجاناً.
   - لتشغيل لوحة التحكم على حسابك في Cloudflare أيضاً، أنشئ مشروع Worker/Pages لمجلد admin-panel/ واربطه بـ KV (DATA) و D1 (DB) و R2 (FILES)، ثم غيّر رابط الـ CMS في website/app.js إلى رابط لوحتك الجديدة.

2) Netlify Drop (أسرع طريقة للموقع العام فقط — دقيقة واحدة):
   - افتح app.netlify.com/drop
   - اسحب مجلد website/ وأفلته في الصفحة، وسيعمل فوراً.

3) GitHub Pages (مجاني عبر حسابك في GitHub):
   - أنشئ Repository جديد في github.com وارفع بداخله ملفات مجلد website/.
   - من Settings > Pages فعّل النشر من الفرع main.

ملاحظة قبل النشر على دومينك الجديد:
- في website/index.html و sitemap.xml و robots.txt و mgu.vcf: غيّر الروابط القديمة إلى رابط موقعك الجديد.
- في website/app.js (السطر الذي يحتوي __CMS_URL): غيّر رابط لوحة التحكم إذا نقلت اللوحة أيضاً، أو اتركه كما هو مؤقتاً.
